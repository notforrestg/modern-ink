/COLOR MAP/

The Modern Ink Color Map is the tool for visualizing the CORE Palette: eighty inks across ten hue families, designed and tested by Russ Abbott. Explore the full range below, build a palette by color scheme, and preview how it may read once healed on different skin tones.

Learn the Ink Names

Every Modern Ink color has a name built from two parts: a hue family and a value/chroma tier. Toggle a tier to see it across all ten hues, or a hue to see its full range from soft to saturated. Combine both to find one exact ink.
